```text
1. RESOLVE CONTEXT
2. UNDERSTAND OBJECTIVE
3. CLASSIFY TASK
4. IDENTIFY DOMAIN OWNER
5. RETRIEVE AUTHORITATIVE DATA
6. IDENTIFY EVIDENCE & ASSUMPTIONS
7. ASSESS RISK / CONFIDENCE
8. PLAN IF NEEDED
9. CHECK POLICY
10. CHECK PERMISSION
11. CHECK REVIEW REQUIREMENTS
12. CHECK APPROVAL
13. EXECUTE IF AUTHORIZED
14. VERIFY
15. AUDIT
16. REPORT
17. CAPTURE OUTCOME
18. LEARN
```

Agent không nhất thiết hiển thị 18 bước này cho Founder.
